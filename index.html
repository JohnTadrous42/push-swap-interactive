HOW TO PLAY

Goal: Sort Stack A in ascending order (smallest number on top). Stack B must be empty.

Evaluation: Your efficiency is analyzed against standard algorithms (O(n²), O(n√n), and O(n log n)). Try to solve it in the minimum amount of moves to achieve the highest algorithmic rating!

Operations Explained

  • sa / sb / ss: (Swap) Swap the first 2 elements at the top of the stack. Does nothing if there is only 1 or no elements. (sa = Stack A, sb = Stack B, ss = Both)
  • pa / pb: (Push) Take the first element at the top of one stack and put it at the top of the other. Does nothing if the source stack is empty. (pa = push to A, pb = push to B)
  • ra / rb / rr: (Rotate) Shift up all elements of the stack by 1. The top element becomes the bottom element. (ra = Stack A, rb = Stack B, rr = Both)
  • rra / rrb / rrr: (Rev. Rotate) Shift down all elements of the stack by 1. The bottom element becomes the top element. (rra = Stack A, rrb = Stack B, rrr = Both)
